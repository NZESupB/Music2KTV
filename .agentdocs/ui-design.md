# TV 界面设计规范

## 设计稿
- AI 概念图：`design/concepts/`（01 首页、02 点歌、05 模板编辑器、06 手机点歌页；03 经典 KTV、04 霓虹 KTV 生成超时，由线框图覆盖）。
- 交互式高保真线框图（含遥控器焦点流模拟）：会话可视化 `music2ktv-tv-wireframes.html`，覆盖首页、点歌、经典 KTV、霓虹频谱、模板编辑、手机点歌 6 屏。
- 状态：**等待用户确认视觉方向**，确认前不编写正式 UI。

## 视觉语言
- 深色夜场：背景 `#0B0820`→`#1C1046` 渐变，主强调 `#FF4FD8`（品红），辅强调 `#3FE0FF`（青），正文 `#EEEAFF`，次要 `#9C94C8`。
- 玻璃卡片：白 6% 填充 + 白 12% 描边，圆角约 16dp。
- 已唱歌词默认青→品红渐变，未唱白色 + 黑色描边。

## 大屏与焦点
- 1920×1080 设计基准，四周 48dp 安全区，最小正文 24sp。
- 焦点态：放大 1.06 + 白色描边 + 品红外发光；单屏焦点区域不超过 2 层。
- 点歌使用屏幕拼音首字母键盘（A–Z、0–9、删除、清空），不调用系统输入法。

## 播放页遥控器
| 键 | 功能 |
|---|---|
| OK | 呼出/隐藏控制条（暂停、下一首、消人声、重唱） |
| ←/→ | 快退/快进 5 秒（无浮层时） |
| 菜单 / 长按 OK | 右侧快捷面板：人声模式、模板、歌词 ±100ms、换一个歌词 |
| 媒体下一首 / 频道+ | 切歌 |
| 返回 | 逐层关闭浮层，最终二次确认退出 |
